# SIPA Nutrition

Marketing and e-commerce site for **SIPA Nutrition**, a vegan Vitamin D3 + K2 daily supplement brand.

🔗 Live: [sipanutrition.com](https://sipanutrition.com)

## Overview

A conversion-focused product site covering the brand story, ingredients, benefits, a results timeline, customer reviews, and an FAQ/policy section, plus a contact flow for customer support.

## Tech Stack

- **Framework:** Next.js
- **UI:** Radix UI primitives, Tailwind CSS
- **Forms:** React Hook Form + resolvers
- **Auth/Data:** NextAuth (MongoDB adapter)
- **Icons:** Font Awesome

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run start` – run the production build
- `npm run lint` – lint the project
